# ProdiQ Planner

Machine-aware production planning for any job shop (VIT ProdiQ project).

All files sit side by side, with no folders, so they can be uploaded to GitHub in one go:
- `app.py` – the whole app
- `requirements.txt` – what Streamlit needs to install
- `sample_*.csv` – two example factories

Put it online: upload all these files to a GitHub repository, then at share.streamlit.io choose *Create app*,
pick the repository and set the main file to `app.py`.
